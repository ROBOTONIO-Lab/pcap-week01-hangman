PyPIPython Package Index, pypi.org: η δημόσια αποθήκη πακέτωνΗ αναζήτηση γίνεται στη σελίδα· το pip search δεν δουλεύει πια
pipΤο εργαλείο που κατεβάζει, εγκαθιστά, αναβαθμίζει και αφαιρεί πακέτα από το PyPIpip --version δείχνει pip και Python
pip install XΕγκαθιστά το X και τις εξαρτήσεις τουΑν υπάρχει ήδη, δεν κάνει τίποτα
pip install -U XΑναβάθμιση στην πιο πρόσφατη έκδοση--upgrade είναι το ίδιο
pip install X==1.2.3Συγκεκριμένη έκδοσηΔύο ίσον
pip install --user XΜόνο για τον τρέχοντα χρήστη, χωρίς δικαιώματα adminΣε κοινόχρηστο υπολογιστή
pip uninstall XΑφαιρεί το X (ρωτάει y/n)Δεν αφαιρεί τις εξαρτήσεις του
pip listΌλα τα εγκατεστημένα πακέτα με εκδόσεις
pip show XΛεπτομέρειες για ένα πακέτο: έκδοση, Requires, Required-byRequires = τι χρειάζεται · Required-by = ποιος το χρειάζεται
pip freezeΕγκατεστημένα πακέτα σε μορφή X==1.2.3Η μορφή του requirements.txt
pip install -r requirements.txtΕγκαθιστά ό,τι γράφει το αρχείοΤο πρώτο που τρέχεις σε νέο υπολογιστή / Codespace
εξάρτηση (dependency)Πακέτο που χρειάζεται άλλο πακέτο για να δουλέψειΤο pip τις λύνει μόνο του
