# Κρεμάλα — PCAP 2026-27 · Εβδομάδα 01

Ένα παιχνίδι κρεμάλας σε terminal, γραμμένο με όσα ξέρεις από το PCEP: λίστες, strings, `while`, `for`, συναρτήσεις, `random`.

## Πώς το τρέχω

Σε **Codespace** (πράσινο κουμπί «Code» → Codespaces → Create codespace on main), στο terminal:

```
python hangman.py
```

## Τι κάνω σήμερα

1. Το τρέχω μία φορά για να δω πώς παίζεται.
2. Ανοίγω το `TASKS.md` και κάνω τα tasks **με τη σειρά**.
3. Μετά από **κάθε** task: Source Control → μήνυμα → Commit → Sync Changes. Ελέγχω στο github.com ότι φαίνεται.

## Κανόνες

- Δουλεύω μόνο μέσα σε αυτό το repo.
- Κάθε commit έχει μήνυμα που λέει τι έκανα (π.χ. `task 2: εμφάνιση προσπαθειών`).
- Αν κολλήσω, γράφω στο `NOTES.md` τι δεν δούλεψε και ζητάω βοήθεια.
